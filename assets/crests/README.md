# CDW Crest Concepts

Five crest design concepts for Canberra Data Week, inspired by the gradients and
brand palette used in `CDW Logo.svg.svg` and `CDW Banner.svg.svg`.

1. **crest-1-shield.svg** — Classic shield with a teal-to-pink gradient and "CDW" wordmark.
2. **crest-2-circular-badge.svg** — Circular badge with purple-to-pink gradient, "CANBERRA / CDW / DATA WEEK" text.
3. **crest-3-data-node-shield.svg** — Shield with a connected data-node motif, warm orange/red gradient.
4. **crest-4-hexagon.svg** — Hexagonal tech-style crest with blue gradient.
5. **crest-5-laurel-emblem.svg** — Circular emblem with laurel-style accents, purple-to-orange gradient.

Pick a favorite as a starting point for the final CDW crest.
